# 运行《超智能决斗》

## 在电脑上开始

安装 Node.js 24 LTS 或更新版本，在克隆的项目根目录运行下面的命令。游戏使用 Node 内置的 SQLite、HTTP 和加密模块，首次启动会自动创建数据库。

```sh
npm start
```

浏览器打开 [本机游戏大厅](http://127.0.0.1:8787/)。单人试炼和同屏对战可以直接以游客身份游玩。注册账号后，服务端会保存力量、Token、晋级进度和衣装。同一台设备上想让第二名玩家操作另一位角色，选择「同屏决斗」。

## 两台设备对战

用同一 Wi-Fi 时，在电脑运行 `npm run lan`，两台设备打开终端打印的局域网地址。两名玩家分别注册并登录，选择「联机排位」，一人创建房间，另一人用房间码加入。双方选好英雄并点击准备后开始。手机横屏使用触控双盘。

玩家使用不同网络时，可将本仓库部署到具备公网域名的服务器。让域名解析至服务器，开放 80、443 端口，安装 Docker 和 Compose，在项目根目录创建只含以下一行的 `.env`，将域名替换成自己的。

```dotenv
ARENA_DOMAIN=duel.example.com
```

```sh
docker compose up -d
```

Caddy 自动申请 HTTPS 证书。两位玩家打开同一域名即可使用同一个账号库和房间服务。微信用户可以直接打开网页版免费游玩。

## 只托管静态网页

将整个 `public/` 部署到静态网站，在 HTTPS 下打开。选角、全部战场、单人和同屏玩法使用同一客户端。静态站的本机档案保存在当前浏览器。双设备实时排位、跨设备账号和全服排行榜需要运行本仓库自带的 Node 服务。双击源文件不提供完整的网页资源加载环境。

## 文件和存档

| 位置 | 内容 |
| --- | --- |
| `public/js/engine.js` | 命中、格挡、能量与回合判定 |
| `public/js/progression.js` | 力量、Token、晋级与衣装规则，前后端共用 |
| `public/js/cpu.js` | 电脑对手的决策与训练赛重演 |
| `public/js/manifest.js`、`public/assets/` | 对战用图集、图片、动作时间与台词文本 |
| `server/` | 账号、SQLite、房间、匹配中断恢复和权威结算 |
| `data/arena.sqlite` | Node 版首次启动后生成的本机数据库 |
| Compose 的 `accounts` 卷 | Docker 部署下的服务器存档 |

运行 `npm test` 可测试晋级、结算、存档和联机房间。要自定义端口或数据库位置，可用 `node server/server.cjs --port 8788 --db ./data/test.sqlite`。备份存档前应正常停止服务，与现有数据库一同保存尚未合并的 WAL 文件。容器更新时保留原有 `accounts` 卷。

游戏客户端使用设备安装的中文语音播放台词。设备缺少中文声音时，仍可看到开场字幕并听到战斗音效与音乐。BreezeBlue 合成的台词仅收录在宣传片成片中。
